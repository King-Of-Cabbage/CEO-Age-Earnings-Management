# Limitations

This repository is derived from a team course research project and is limited to the cleaned reproducible implementation. It does not include the full course report, full course slides, licensed raw data, company names, CEO names, student identifiers, or teacher materials.

Some standard errors, R-squared values, and significance markers in the historical course report could not be precisely recovered in the current Python environment. The public repository therefore uses a transparent and consistent PanelOLS setup and firm-clustered standard errors for the main layer.

The course report contained IV and OPRISK-related analyses, but the instrument construction and mechanism-analysis chains were not locked reliably. They are excluded from the public reproducible claims.
