# Data Access

The source data for this project comes from licensed financial databases and is not included in this repository.
Users who are permitted to access the data must prepare a local file with the fields listed in `data/required_schema.csv` and point `config.local.yaml` to that file.

The repository does not download CSMAR, Wind, RESSET, or other licensed datasets. It does not include company names, CEO names, student identifiers, or personal information.
